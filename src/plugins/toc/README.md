# toc

![toc-desktop-hover](/docs/images/toc-desktop-hover.png)

본문 제목(heading)을 기준으로 목차를 생성하는 플러그인입니다. 데스크톱에서는 레일형 목차를, 좁은 화면에서는 팝업형 목차를 표시하며, 현재 보고 있는 섹션을 강조합니다.

## 주요 기능

- `h2`, `h3`, `h4` 제목을 기준으로 목차를 생성합니다.
- 데스크톱에서는 본문 우측 레일형 TOC를, 좁은 화면에서는 하단 버튼으로 여는 모바일 TOC를 표시합니다.
- 제목에 `id`가 없으면 텍스트 기반 slug에 `rp-` 접두사를 붙여 ID를 생성하고, 중복 시 고유한 값으로 보정합니다.
- 목차 항목을 클릭하면 해시를 갱신하고 고정 헤더 높이를 반영해 해당 섹션으로 스크롤합니다.
- 이동 대상 앞의 이미지·iframe·video 등이 아직 자리를 잡지 않은 경우 짧게 대기한 뒤 스크롤하며, 이후 레이아웃 변화가 감지되면 위치를 보정합니다.
- 스크롤 위치에 따라 현재 섹션을 강조합니다.
- 화면 폭과 우측 여백이 충분하면 레일형을, 그렇지 않으면 모바일 팝업형으로 자동 전환합니다.

## 본문 컨테이너 감지

본문 컨테이너 감지 방식(셀렉터, `window.RPPlugins.articleSelectors`)은 [링크](../../../README.md#본문-컨테이너-감지)를 참고해주세요.

## 처리 대상

- 기본 제목 셀렉터: `h2`, `h3`, `h4`
- 기본 헤더 오프셋: `84px`
- 데스크톱 레일 최소 표시 폭: `1280px`

제목이 2개 이상일 때만 목차를 렌더링합니다.

## 선택 설정

`window.RPPlugins.toc`로 제목 레벨과 헤더 오프셋을 조정할 수 있습니다. 설정 코드는 스크립트보다 먼저 선언해야 합니다.

```html
<script>
  window.RPPlugins = {
    toc: {
      levels: [2, 3, 4, 5],
      headerOffset: 64,
    },
  };
</script>
```

- `levels`: 목차에 포함할 제목 레벨.
- `headerOffset`: 스크롤 보정에 사용할 헤더 오프셋(px).

## 설치 방법

티스토리 HTML 편집 페이지에서 아래 코드를 `</body>` 위에 삽입합니다. 스크립트 실행 시 같은 경로의 `index.min.css`를 자동으로 로드합니다.

```html
<script defer src="https://cdn.jsdelivr.net/gh/romantech/tistory-plugins@latest/dist/toc/index.min.js"></script>
```

## 동작 흐름

1. 본문에서 설정된 레벨의 제목을 찾습니다.
2. 각 제목의 최종 `id`를 결정합니다.
3. 우측 여백이 충분하면 레일형 목차를, 그렇지 않으면 팝업형 목차를 렌더링합니다.
4. 목차 클릭 시 해시를 갱신하고 헤더 높이를 반영해 스크롤합니다.
5. 대상 제목 앞에 로딩 중인 리소스가 있으면 짧게 대기합니다.
   - 리소스가 안정되거나 대기 시간이 지나면 스크롤을 진행합니다.
   - 스크롤 후 제목 위치가 변경되면 헤더 오프셋에 맞게 재보정합니다.
6. 스크롤·리사이즈 시 현재 섹션 강조와 레이아웃 모드(데스크톱/모바일)를 재계산합니다.

## 참고 사항

- 본문 뒤에 `.another-category` 영역이 있으면 그 구간까지 본문 영역으로 간주하여 목차를 유지합니다.
- 플러그인이 생성하는 ID는 `rp-` 접두사를 사용해 스킨의 기존 ID(예: `#pagination`)와의 충돌을 방지합니다.
- `heading-anchor` 플러그인과 함께 사용해도 동일한 ID 규칙을 공유하므로 충돌하지 않습니다.
