# toc

![본문 옆 목차에 마우스를 올렸을 때의 모습](/docs/images/toc-desktop-hover.png)

티스토리 본문 제목으로 목차를 만들고, 읽고 있는 섹션을 표시합니다. 넓은 화면에서는 본문 오른쪽에, 좁은 화면에서는 버튼으로 여는 팝업에 목차를 보여줍니다.

## 설치

스킨 HTML 편집에서 `</body>` 바로 위에 스크립트를 추가합니다. CSS는 자동으로 불러옵니다.

```html
<script defer src="https://cdn.jsdelivr.net/gh/romantech/tistory-plugins@latest/dist/toc/index.min.js"></script>
```

## 사용법

기본적으로 `h2`, `h3`, `h4`를 모으며, 대상 제목이 2개 이상일 때만 목차를 표시합니다. 목차 항목을 누르면 URL 해시를 갱신하고 해당 제목으로 이동합니다.

| 화면 | 표시 방식 |
| --- | --- |
| 폭이 `1280px` 이상이고 본문 오른쪽 여백이 충분할 때 | 본문 옆 목차 |
| 그보다 좁거나 오른쪽 공간이 부족할 때 | 화면 하단의 버튼으로 여는 팝업 목차 |

팝업은 바깥을 누르거나 `Esc` 키로 닫을 수 있습니다. 버튼을 위아래로 끌어 위치를 옮길 수도 있습니다.

이동할 제목 앞의 이미지·영상 등이 로딩 중이면 잠시 기다렸다가 스크롤합니다. 이동 후에도 제목 위치가 바뀌면 고정 헤더 높이에 맞춰 다시 조정합니다.

본문을 찾는 방식과 스킨별 설정은 [본문 컨테이너 감지](../../../README.md#본문-컨테이너-감지)를 참고하세요.

## 설정

플러그인 스크립트 앞에 선언합니다.

```html
<script>
  window.RPPlugins = {
    toc: {
      levels: [2, 3, 4, 5],
      headerOffset: 64,
    },
  };
</script>
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `levels` | `[2, 3, 4]` | 목차에 포함할 제목 레벨. 1~6 지정 가능 |
| `headerOffset` | CSS 변수 또는 `84` | 이동한 제목 위에 남길 공간(px) |

`headerOffset`을 지정하지 않으면 `:root`의 `--header-height`를 읽고, 값이 없으면 `84px`를 사용합니다. `heading-anchor`와 함께 쓴다면 두 플러그인의 오프셋을 같게 설정하세요.

## 참고

- 제목에 `id`가 없으면 텍스트를 바탕으로 `rp-`로 시작하는 ID를 만듭니다. 중복된 ID는 숫자를 붙여 구분합니다. `heading-anchor`와 같은 규칙을 사용합니다.
- 카테고리의 다른 글, 공유 버튼, 댓글 영역의 제목은 목차에서 제외합니다.
- 본문 안에 `.another-category` 또는 `.another_category` 영역이 있으면 그 구간까지 목차를 유지합니다.
