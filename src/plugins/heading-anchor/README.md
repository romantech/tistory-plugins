# heading-anchor

![제목 링크를 눌러 해당 섹션으로 이동하는 모습](/docs/images/heading-anchor.gif)

티스토리 본문 제목에 `#` 링크를 추가합니다. 링크로 이동할 때 고정 헤더가 제목을 가리지 않도록 스크롤 위치를 조정합니다.

## 설치

스킨 HTML 편집에서 `</body>` 바로 위에 스크립트를 추가합니다. CSS는 자동으로 불러옵니다.

```html
<script defer src="https://cdn.jsdelivr.net/gh/romantech/tistory-plugins@latest/dist/heading-anchor/index.min.js"></script>
```

## 동작

기본 대상은 `h2`, `h3`, `h4`입니다. 제목을 클릭하면 URL 해시를 갱신하고 해당 위치로 부드럽게 이동합니다. 브라우저 방문 기록은 추가하지 않습니다.

- 제목에 `id`가 없으면 제목 텍스트로 만듭니다. 예를 들어 `설치 방법`은 `rp-설치-방법`이 됩니다. 같은 ID가 있으면 숫자를 붙여 구분합니다.
- 제목 안에 이미 링크가 있으면 ID만 부여하고, 제목 링크와 `#` 표시는 추가하지 않습니다.
- 해시가 포함된 URL로 글을 열면 폰트·페이지 로딩과 뷰포트 변화를 반영해 위치를 다시 맞춥니다. 브라우저의 뒤로·앞으로 가기로 페이지가 복원될 때도 보정합니다.

본문을 찾는 방식과 스킨별 설정은 [본문 컨테이너 감지](../../../README.md#본문-컨테이너-감지)를 참고하세요.

## 설정

플러그인 스크립트 앞에 선언합니다.

```html
<script>
  window.RPPlugins = {
    headingAnchor: {
      levels: [2, 3, 4, 5],
      headerOffset: 64,
    },
  };
</script>
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `levels` | `[2, 3, 4]` | 링크를 추가할 제목 레벨. 1~6 지정 가능 |
| `headerOffset` | CSS 변수 또는 `84` | 제목 위에 남길 공간(px) |

`headerOffset`을 지정하지 않으면 `:root`의 `--header-height`를 읽고, 값이 없으면 `84px`를 사용합니다. `toc`와 함께 쓴다면 두 플러그인의 오프셋을 같게 설정하세요.

## 참고

- 스킨에서 제목 안의 링크 스타일을 지정하고 있다면 플러그인 스타일과 함께 확인하세요.
- 해시로 처음 이동한 직후에는 위치를 다시 맞추면서 짧은 추가 스크롤이 생길 수 있습니다.
