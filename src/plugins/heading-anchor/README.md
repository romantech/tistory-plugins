# heading-anchor

티스토리 본문 제목에 앵커 링크를 자동으로 추가하는 플러그인입니다. 제목을 클릭하거나 제목 우측 `#` 앵커를 클릭하면 현재 섹션의 URL 해시를 갱신하고, 고정 헤더 높이를 고려해 해당 위치로 부드럽게 스크롤합니다. 이미지가 많거나 폰트/뷰포트 변화가 있는 글에서 해시 링크 진입 시 스크롤 위치가 어긋나는 문제를 줄이기 위해, 페이지 로드 이후 여러 시점에 걸쳐 스크롤 위치를 자동으로 재보정합니다.

## 주요 기능

- `h2`, `h3`, `h4` 제목 요소에 `#` 앵커 링크 자동 추가
- 제목 클릭 시 현재 섹션의 URL 해시를 갱신하고 해당 위치로 부드럽게 스크롤
- 제목에 `id`가 없으면 텍스트 기반 `slug`를 생성하고, 중복 시 고유 ID로 보정
- 초기 해시 링크 진입 시 폰트 로딩 완료 후 스크롤 위치 보정 수행
- 페이지 로드 직후와 이후 여러 지연 시점에서 반복 보정하여 이미지 많은 글의 오차 완화
- `visualViewport.resize` 변화를 잠시 감시하여 초기 진입 직후 레이아웃 변동 대응
- CSS 변수 `--header-height` 값을 기준으로 고정 헤더 높이 반영

## 대상 컨테이너

티스토리 스킨별 차이를 고려하여 여러 본문 컨테이너 후보 중 먼저 발견되는 영역에서 동작합니다.

- `#article`
- `.article-view`
- `.area_view`
- `.entry-content`
- ...

## 대상 요소

다음 제목 요소를 처리합니다.

- `h2`
- `h3`
- `h4`

## 사용 방법

### 1. CSS 추가하기

아래 CSS를 티스토리 HTML 편집기의 `</head>` 태그 앞에 삽입합니다.

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/romantech/tistory-plugins@latest/dist/heading-anchor/index.min.css">
```

### 2. 자바스크립트 추가하기

아래 스크립트를 티스토리 HTML 편집기의 `</body>` 태그 앞에 삽입합니다.

```html
<script src="https://cdn.jsdelivr.net/gh/romantech/tistory-plugins@latest/dist/heading-anchor/index.min.js"></script>
```

## 동작 방식

1. 본문 영역에서 `h2`, `h3`, `h4`를 찾습니다.
2. 각 제목에 사용할 고유 `id`를 확정합니다.
3. 제목 내부 텍스트를 앵커 링크로 감싸고, 우측에 `#` 마커를 추가합니다.
4. 사용자가 제목 링크를 클릭하면 URL 해시를 갱신한 뒤 헤더 높이를 반영해 부드럽게 스크롤합니다.
5. 해시가 포함된 URL로 직접 진입한 경우, 초기 렌더 직후 한 번만 맞추는 대신 폰트 로딩 완료, `load` 이후, 추가 지연 시점, 뷰포트 변화 시점에 재보정을 수행해 위치 오차를 줄입니다.

## 주의 사항

- 이 플러그인은 런타임에서 제목 요소에 앵커 링크와 ID를 동적으로 추가합니다.
- 제목에 이미 `id`가 있어도 문서 내 중복 가능성을 검사한 뒤 필요하면 고유 ID로 보정합니다.
- 제목 내부에 이미 앵커 링크가 있으면 중복 삽입하지 않습니다.
- 제목 내부에 다른 `<a>` 요소가 있으면 링크 중첩을 피하기 위해 앵커 래핑을 생략합니다.
- 초기 해시 보정은 최대한 보수적으로 여러 번 수행되므로, 환경에 따라 아주 짧은 추가 위치 보정이 보일 수 있습니다.
- 스킨 구조, 비동기 이미지 로딩 방식, 광고/위젯 삽입 여부에 따라 초기 해시 보정 결과는 일부 달라질 수 있습니다.

## 헤더 높이

고정 헤더 높이는 CSS 변수로 조정할 수 있습니다.

```css
:root {
  --header-height: 84px;
}
```
